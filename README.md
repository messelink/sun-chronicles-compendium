# The Sun Chronicles — Compendium & Topology Map

A fan-made reference for the worldbuilding of Kate Elliott's *Sun Chronicles* science-fiction series (*Unconquerable Sun*, *Furious Heaven*, and the forthcoming *Lady Chaos*): the interstellar beacon network topology, stellar geography, political entities, travel technology, and key strategic situations.

> Unofficial and unaffiliated. All facts are drawn from the published novels and cited; only short fair-use excerpts are quoted. Copyright in the *Sun Chronicles* belongs to Kate Elliott. This project does not reproduce the books.
